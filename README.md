# Stuart Bowness

Founder and builder in Victoria, BC. I build AI tools and Mac apps.

## Projects

### [Darkfactory](https://github.com/stuartbowness/darkfactory)

A team of AI coding agents that plans, builds, and reviews software. Built around Claude Code and Codex.

### [TestKitchen](https://github.com/stuartbowness/testkitchen)

A testing toolkit for AI agents. Give them tasks and check whether they actually did the work.

### [Iron Search](https://github.com/stuartbowness/ironsearch)

A fast Mac launcher for apps and contacts. Open it, type a few letters, and go.

### [Iron Zapper](https://github.com/stuartbowness/ironzapper)

The Mac uninstaller Apple forgot to include. Drag in an app, see what it left behind, and move it to Trash.

All four are open source under the MIT license.
